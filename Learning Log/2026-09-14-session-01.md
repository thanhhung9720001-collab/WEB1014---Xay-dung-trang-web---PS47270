# \### 2. HTML là gì?

# \- HTML là viết tắt của \*\*HyperText Markup Language\*\*.

# \- HTML là \*\*ngôn ngữ đánh dấu\*\*, dùng để tạo cấu trúc và nội dung cho trang web.

# \- HTML không phải là ngôn ngữ lập trình.

# \- Trình duyệt đọc mã HTML và hiển thị nội dung thành trang web.

# 

# \### 3. Cấu trúc cơ bản của một file HTML

# 

# ```html

# <!DOCTYPE html>

# <html>

# <head>

# &#x20;   <title>Tiêu đề trang</title>

# </head>

# <body>

# &#x20;   Nội dung trang web

# </body>

# </html>

# ````

# 

# Vai trò của từng phần:

# 

# \* `<!DOCTYPE html>`:

# 

# &#x20; \* Khai báo tài liệu sử dụng HTML5.

# &#x20; \* Giúp trình duyệt hiểu cách xử lý trang HTML.

# 

# \* `<html>`:

# 

# &#x20; \* Là thẻ gốc.

# &#x20; \* Bao toàn bộ nội dung của tài liệu HTML.

# 

# \* `<head>`:

# 

# &#x20; \* Chứa các thông tin về trang web.

# &#x20; \* Thông thường không hiển thị trực tiếp trong phần nội dung trang.

# 

# \* `<title>`:

# 

# &#x20; \* Nằm trong `<head>`.

# &#x20; \* Dùng để đặt tiêu đề hiển thị trên tab trình duyệt.

# 

# \* `<body>`:

# 

# &#x20; \* Chứa nội dung chính hiển thị cho người dùng.

# &#x20; \* Phần lớn code HTML tạo nội dung trang web sẽ nằm trong thẻ này.

# 

# \### 4. Các thẻ HTML cơ bản

# 

# \#### Thẻ tiêu đề

# 

# ```html

# <h1>Tiêu đề lớn nhất</h1>

# <h2>Tiêu đề cấp 2</h2>

# ...

# <h6>Tiêu đề cấp 6</h6>

# ```

# 

# \* Có từ `<h1>` đến `<h6>`.

# \* `<h1>` là tiêu đề cấp cao nhất.

# \* Các thẻ `h` dùng để tạo tiêu đề cho nội dung.

# 

# \#### Thẻ đoạn văn

# 

# ```html

# <p>Đây là một đoạn văn.</p>

# ```

# 

# \* `<p>` dùng để tạo một đoạn văn.

# 

# \#### Thẻ nhấn mạnh

# 

# ```html

# <em>Nội dung được nhấn mạnh</em>

# ```

# 

# \* `<em>` dùng để nhấn mạnh một phần nội dung.

# \* Trình duyệt thường hiển thị nội dung trong `<em>` bằng chữ nghiêng.

# 

# Ví dụ:

# 

# ```html

# <p>Tôi đang học <em>HTML cơ bản</em>.</p>

# ```

# 

# Khác nhau:

# 

# \* `<p>` = tạo một đoạn văn.

# \* `<em>` = nhấn mạnh một phần nội dung bên trong câu hoặc đoạn văn.

# 

# \#### Thẻ in đậm

# 

# ```html

# <b>Chữ in đậm</b>

# <strong>Nội dung quan trọng</strong>

# ```

# 

# \* `<b>` thường dùng để hiển thị chữ đậm.

# \* `<strong>` cũng thường hiển thị chữ đậm nhưng còn mang ý nghĩa nội dung quan trọng.

# 

# \#### Thẻ chỉ số trên

# 

# ```html

# x<sup>2</sup>

# ```

# 

# Hiển thị:

# 

# x²

# 

# \#### Thẻ chỉ số dưới

# 

# ```html

# H<sub>2</sub>O

# ```

# 

# Hiển thị:

# 

# H₂O

# 

# \#### Thẻ xuống dòng

# 

# ```html

# Dòng 1<br>

# Dòng 2

# ```

# 

# \* `<br>` dùng để xuống dòng.

# \* Không cần thẻ đóng.

# 

# \#### Thẻ đánh dấu nội dung

# 

# ```html

# <mark>Nội dung cần làm nổi bật</mark>

# ```

# 

# \* `<mark>` dùng để đánh dấu/làm nổi bật văn bản.

# \### 7. Tóm tắt ngắn

# 

# \* HTML dùng để tạo cấu trúc trang web.

# \* Nội dung chính hiển thị trên trang thường nằm trong `<body>`.

# \* `<title>` đặt tên cho tab trình duyệt.

# \* `<h1>` → `<h6>` dùng cho tiêu đề.

# \* `<p>` dùng cho đoạn văn.

# \* `<em>` dùng để nhấn mạnh nội dung.

# \* `<strong>` / `<b>` thường hiển thị chữ đậm.

# \* `<sup>` là chỉ số trên.

# \* `<sub>` là chỉ số dưới.

# \* `<br>` xuống dòng.

# \* `<mark>` làm nổi bật văn bản.
